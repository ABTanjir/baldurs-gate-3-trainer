## Vor dem Start

1. Sichere deine Spielstände außerhalb des Spielordners.
2. Nutze Drittanbieter-Tools nur offline und im Einzelspieler-Modus.
3. Vergleiche Spielversion, Store-Build und Release-Hinweise.
4. Schalte den Virenschutz nicht blind aus. Prüfe Warnungen, Signatur und Hashwert.

## Installation und erster Test

1. Beende das Spiel und den Launcher vollständig.
2. Öffne den Download-Link und lies die Hinweise im aktuellen Paket.
3. Entpacke das Archiv in einen eigenen Ordner.
4. Starte zuerst das Tool und danach das Spiel, sofern die Release-Hinweise nichts anderes sagen.
5. Aktiviere beim ersten Test nur eine Option.

## Trainer, Save Editor oder Cheat Engine Table?

Ein Trainer ändert Werte während des Spiels. Ein Save Editor bearbeitet eine gespeicherte Datei. Eine Cheat Engine Table benötigt Cheat Engine. Prüfe die Release-Hinweise, bevor du vom Dateinamen auf das Format schließt.

## Häufige Fragen

### Funktioniert Baldur's Gate 3 Trainer für PC mit dem neuesten Update?

Nur wenn der veröffentlichte Build mit der installierten Spielversion übereinstimmt und alle Funktionen erneut getestet wurden.

### Kann ich Baldur's Gate 3 Trainer für PC online verwenden?

Nein. Nur offline und im Einzelspieler-Modus verwenden.
