## Before you run the trainer

1. Copy your save files outside the game directory.
2. Use third-party tools only in offline single-player play.
3. Match the installed game build and storefront with the release notes.
4. Check the published SHA-256 value before opening the file.
5. Investigate security warnings. Do not disable protection or create broad exclusions just to make a file run.

## Setup and first test

1. Close the game and its launcher completely.
2. Open the download link and read the notes included with the current package.
3. Extract the archive into a separate folder. Do not mix it with an older build.
4. Start the tool, then start the game unless the package gives a different order.
5. Enable one option and confirm that the game remains stable.
6. Close the tool before returning to any online or shared mode.

## Tool format

A trainer changes values while the game is running. A save editor changes data stored in a save file. A Cheat Engine table requires Cheat Engine and usually targets a specific executable build. This package is a standalone trainer.

## Troubleshooting

- Nothing changes: compare the installed build with **v4.1.1, Patch 8 (Windows PC)** before changing permissions.
- The tool closes immediately: inspect the security alert, signature, SHA-256 and download source.
- The game crashes: remove other gameplay tools, overlays and framework mods, then test a clean launch.
- A save no longer loads: stop testing and restore the untouched backup.
- Only some controls work: record the build as incompatible and fix the failed tests before release.
