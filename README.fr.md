## Avant de commencer

1. Copiez vos sauvegardes dans un dossier séparé.
2. Utilisez les outils tiers uniquement hors ligne et en solo.
3. Comparez la version du jeu, la boutique et les notes de version.
4. Ne désactivez pas votre antivirus sans vérifier l'alerte, la signature et le hash du fichier.

## Installation et premier test

1. Fermez complètement le jeu et son launcher.
2. Ouvrez le lien de téléchargement et lisez les notes du paquet actuel.
3. Extrayez l'archive dans un dossier séparé.
4. Lancez l'outil puis le jeu, sauf indication contraire dans les notes de version.
5. N'activez qu'une seule option lors du premier test.

## Trainer, éditeur de sauvegarde ou table Cheat Engine ?

Un trainer modifie des valeurs pendant la partie. Un éditeur de sauvegarde change un fichier de sauvegarde. Une table Cheat Engine nécessite Cheat Engine. Consultez les notes de version avant de déduire le format à partir du nom du fichier.
